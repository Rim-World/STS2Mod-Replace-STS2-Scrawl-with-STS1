# ADR-001：潦草急就整卡替换为 STS1 样式

- 日期：2026-08-15
- 状态：已接受

## 背景

杀戮尖塔 2（default 107 / public beta 111）无色金卡「潦草急就」（Scrawl）与杀戮尖塔 1
同名卡仅升级效果不同：STS2 升级 = 获得 Retain（保留，仍 1 费）；STS1 升级 = 费用 1→0
（保留 Exhaust）。用户希望整卡替换为 STS1 样式。

## 决策

1. **升级行为**：补丁 `Scrawl.OnUpgrade`（Prefix 返回 false），由 `AddKeyword(Retain)` 改为
   `__instance.EnergyCost.UpgradeBy(-1)`（官方样板：ShadowStep 同款写法）。
   - 基础版不变（1 费 + Exhaust + 抽满手牌，两版一致），`OnPlay` 不补丁。
2. **卡名/描述**：15 语言覆盖为 STS1 原文（去 Exhaust 句；zht 按用户要求补句号），键
   `RE_SCRAWL.title/.description`，通过 `CardModel.TitleLocString` / `Description` getter Postfix 切换。
3. **卡图**：`Portrait` / `PortraitPath` / `PortraitPngPath` 三 getter 指向 STS1 原版卡图
   （500×380 → RGBA → 1000×760 + 250×190），DLL 内嵌 PNG 兜底。
4. **版本兼容**：单 DLL 通吃 107/111（两版 `Scrawl.cs` 与 `CardEnergyCost.UpgradeBy` 逐字一致，
   已用 decompiled-107 实证）；manifest `min_game_version=0.107.1`。
5. **维护策略**：不加形状守卫（用户决定），仅靠 min_game_version + 每次游戏更新后反编译比对兜底。
6. **mod 信息**：名称「潦草急就 (Scrawl)」，无 author 字段（用户要求），版本 1.0；
   模组图标为 420×420 灰色占位（用户后补）。
7. **ind 语言**：111 有第 16 语言 ind，本 mod 暂按用户批准的 15 语言构建；ind 玩家会 LocException，
   待用户决定是否补齐（文本已备）。

## 后果

- 最小补丁面（6 处 Harmony 补丁：OnUpgrade + 2 文本 + 3 卡图），与既有同类 mod 同一模式。
- 未来版本若 `OnUpgrade` 签名或卡机制变动，`PatchAll` 异常被 ModEntry try/catch 捕获，mod 失效不崩游戏。
- 107/111 单 DLL：切换分支无需重新构建。
