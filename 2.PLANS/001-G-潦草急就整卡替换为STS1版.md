# 计划：STS2 潦草急就（Scrawl）整卡替换为 STS1 版

状态：调研完成，待用户确认决策项后开工

## 一、背景与目标

将杀戮尖塔 2 无色金卡「潦草急就」（Scrawl）整卡替换为杀戮尖塔 1 同名卡牌：
升级效果、卡名、卡面描述、卡图全部换成 STS1 样式。

- 适配版本：default v0.107.1 与 public beta v0.111.0（本机当前 v0.111.0）
- 适配平台：Windows 11 / macOS（arm64 + x86_64）
- 未来版本：以最小补丁面 + 运行时防护实现"无感兼容"，不刻意绑定具体版本

> 说明：用户所称「潦草急就」即英文 Scrawl。已在 STS1 正版 jar（`desktop-1.0.jar`）
> 中确认 `localization/zhs/cards.json` 的「潦草」命中键为 `Scrawl`；
> STS2 中同名词条为 `SCRAWL.title`（zhs=潦草急就）。两作英文名、中文名均一致。

## 二、已取证结论（2026-08-15，本机 v0.111.0 反编译 + STS1 jar 实证）

### 2.1 STS2 侧（外部反编译产物 `decompiled-111/.../Models/Cards/Scrawl.cs`，逐字；该目录未随本仓库保存）

`MegaCrit.Sts2.Core.Models.Cards.Scrawl`：

- 构造 `base(1, CardType.Skill, CardRarity.Rare, TargetType.Self)`：**1 费 / 技能 / 稀有(金) / 自身**，无色卡池成员
  （`ColorlessCardPool.GenerateAllCards` 含 `ModelDb.Card<Scrawl>()`）
- `CanonicalKeywords = [Exhaust]`（消耗）
- `OnPlay`：`CardPile.MaxCardsInHand - Hand.Cards.Count` 后 `CardPileCmd.Draw(...)`（抽牌直到手牌补满）
- `OnUpgrade`：**`AddKeyword(CardKeyword.Retain)`** ← 与 STS1 的差异点
- 本地化键：`SCRAWL.title` / `SCRAWL.description`（单个描述键，不区分升级）
  - zhs 描述：`抽牌直到抽满[gold]手牌[/gold]。`（无关键词文字，Exhaust/Retain 由 UI 徽记渲染）
  - 注意：STS2 中**不存在** Scribble 卡（全库无 SCRIBBLE 键/类），潦草急就即 Scrawl

### 2.2 STS1 侧（正版 `desktop-1.0.jar` 反编译 + 官方 wiki 交叉验证）

`com/megacrit/cardcrawl/cards/purple/Scrawl.class`（观者卡）：

- 1 费 / Rare / Skill / 单体；效果"抽牌直到将手牌抽满。消耗"
- `upgrade()` 字节码引用 `upgradeBaseCost`（wiki 实证：费用 1→0，升级后 0 费、效果不变）
- `UPGRADE_DESCRIPTION` 为空（升级文本 = 基础文本，仅费用变化）
- 卡图：`images/1024Portraits/purple/skill/scrawl.png`（**500×380**，已实测 50,324 字节）

两版差异汇总：**仅升级效果不同**——STS2 升级=+Retain（仍 1 费仍消耗）；
STS1 升级=费用 1→0（保留消耗）。基础效果（抽满手牌+消耗）两版一致，`OnPlay` 无需补丁。

### 2.4 实现可行性（反编译证实）

- STS2 官方升级减费样板：`ShadowStep.OnUpgrade` = `base.EnergyCost.UpgradeBy(-1)`
  （`MegaCrit.Sts2.Core.Models.Cards.ShadowStep.cs:26-29`，v0.111 实证）。
  Scrawl 升级费用 1→0 直接复用此写法，是引擎原生 API、升级流程内安全（无计算下注
  先例中"改 CanonicalEnergyCost + 清缓存"的坑——那是改基础费场景，本卡是升级场景）。
- 升级预览/图鉴路径：`MutableClone() + UpgradeInternal()` → 调用 `OnUpgrade()`，补丁自然生效
  （计算下注先例已验证此链路）。
- `CardModel.AddKeyword/RemoveKeyword`（CardModel.cs:1330/1337）public，OnUpgrade 内调用安全。
- `LocString` 构造：`new LocString("cards", "RE_SCRAWL.title")`（`MegaCrit.Sts2.Core.Localization`）。
- 卡图三 getter：`Portrait` / `PortraitPath` / `PortraitPngPath`（CardModel.cs:157/143/149）可补丁替换。

## 三、技术方案

### 3.1 行为补丁（仅 1 处核心）

`Scrawl.OnUpgrade`（Prefix 返回 false 整体替换）：

```csharp
[HarmonyPatch(typeof(Scrawl), "OnUpgrade")]
Prefix(Scrawl __instance) {
    if (ModConfig.IsReplaceEnabled /* && ShapeGuard.Ok（如启用） */) {
        __instance.EnergyCost.UpgradeBy(-1);  // 不再 AddKeyword(Retain)；1 费 → 0 费
        __result = false;
    }
}
```

效果：基础版维持 1 费 + Exhaust（抽满手牌，与 STS1 一致）；升级版 0 费 + Exhaust（无 Retain），
与 STS1 完全一致。`OnPlay` 无需补丁。

### 3.2 文本补丁（卡名 + 描述）

- `CardModel.TitleLocString` / `CardModel.Description` getter Postfix：
  `__instance is Scrawl` 时切到模组专属键 `RE_SCRAWL.title/.description`
  （`RE_` 前缀防与 CustomCardBalance 等 mod 冲突，与既有先例一致）。
- 描述内容：STS1 原文去掉尾部 Exhaust 句（`NL`→`\n`），按用户决策决定是否保留高亮（见七）。

### 3.3 卡图补丁

- `CardModel.Portrait` / `PortraitPath` / `PortraitPngPath` 三 getter 指向模组内
  `res://ScrawlReplacementMod/images/card_portraits/big/scrawl.png`（1000×760）。
- 复用 `PortraitTextureLoader` 模式：pck 优先，失败回退 DLL 内嵌 PNG。

### 3.4 素材清单

- 卡图：STS1 500×380 → RGBA → LANCZOS 2× → 1000×760 + 250×190。
- 本地化：15 个语言目录（zhs/zht/eng/jpn/kor/spa/esp/ptb/fra/deu/rus/ita/pol/tha/tur）
  + **111 新增 ind**，共 16 目录，各生成 `cards.json`（esp 复用 spa）。
- 模组图标 `mod_image.png`（420×420，创意工坊用，可先用纯色占位）。
- pck 打包：Godot 4.5.1 export-pack（先例模式）。

## 四、实施步骤

1. 初始化工程：`9.SRC/ScrawlReplacementMod/`（csproj / ModEntry / ModConfig / Patches / build.ps1），

2. **107 反编译比对**（见七）：确认 `Scrawl` 与 `CardModel.EnergyCost.UpgradeBy` 在 107 的形态；

3. 生成本地化 16 目录 `cards.json`（从 STS1 jar 提取 → 转写 → 落盘，`NL`→`\n`、去 Exhaust 句）。

## 六、风险与兜底

1. **107 形态差异**：107 若 `Scrawl.OnUpgrade`/`EnergyCost.UpgradeBy` 签名不同，按先例两种方案：
   运行时反射分派（Reaper 模式）或分支守卫 + min_game_version 收紧（CorpseExplosion 模式）。
2. **图鉴滚动闪动**（先例曾现）：沿用 PhantomKillerMod 1.0 已实测稳定模式；若复现，按先例修复
   （Portrait 改返 250×190、热路径 try/catch）。
3. **未来版本改动 `Scrawl`**：可选形状守卫（检查升级前实例含 Exhaust、无 Retain、1 费、Self 目标）；
   `PatchAll` 异常被 ModEntry try/catch 捕获，mod 失效不崩游戏；每次更新后跑反编译比对。
4. **键冲突**：`RE_SCRAWL.*` 模组专属前缀，规避第三方 mod。
